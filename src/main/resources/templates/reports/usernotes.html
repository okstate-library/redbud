User Notes - Help

This report displays user notes created by administrators. The User Note Type drop-down lists all available note types. Selecting a specific note type filters the grid to display only the notes associated with that type. The last column provides the option to delete a note. Please be aware that deleting a note is permanent and cannot be undone or recovered. Therefore, it is strongly recommended that you review and test the report carefully before deleting any notes.
